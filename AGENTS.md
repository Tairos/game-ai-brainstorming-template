# Game brainstorming project

This repository contains project-local skills for exploratory game ideation. Read the relevant skill directly; no plugin installation is needed.

- For generating or branching one-line sparks, read [tai-brainstorm-discover](skills/tai-brainstorm-discover/SKILL.md).
- For the phases and their outputs, read [README.md](README.md): Discover → Spark, Define → Concept, Develop → Direction, Deliver → Blueprint.
- For template maintenance, edit the instructions and assets without treating examples as requests to generate game ideas.
- Preserve the offline [HTML map](assets/map.html). Read [its data format](assets/map-format.md) when populating it.

Discover accepts ambiguity and free branching. Do not require sparks to solve a problem, describe playable mechanics, or remain aligned with their original root. Preserve ancestry without turning it into a constraint. Distinguish assistant proposals from user choices.

Keep instructions provider-neutral and links relative. Do not infer game constraints from the template’s development history. All skills use the `tai-` prefix, short for Tairos Artificial Intelligence (TAI). Keep folder and frontmatter names identical and add routing here for new skills.
